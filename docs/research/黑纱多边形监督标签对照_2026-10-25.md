# 黑纱 `detect` 多边形监督标签对照

日期：2026-10-25。目的：验证旧 M1 实验把人工 `detect` 多边形改成外接矩形，是否明显损害训练信号。本轮只改变 M1 的训练和验证标签；复用既有 DINOv2 异常图缓存、同一 1 通道 CNN、随机种子、六折留相机划分、20 轮训练、P95 正常验证阈值及定位评分。M0 不重跑，原始图像和 JSON 不修改，F2 不参与。

## 输入和标签

七月黑纱批按 SHA-256 去重后为 69 帧，其中 16 张各有一个 `detect` 多边形，其余 53 张没有 `detect`；每张图还带一个 `KC` 区域矩形，M1 代码未读取 `KC` 作为监督目标，裁剪使用固定高度比例。DINOv2 是冻结特征提取器；本轮没有微调骨干。完整输入见 `tools/verify_polygon_supervision.py` 和旧 M1 索引。

旧标签规则：patch 中心落入 `detect` 多边形的**外接矩形**记正。新标签规则：同一 patch 中心落入原始 `detect` 多边形记正。两种标签都只在现有 patch 网格上定义，不声称达到原图像素级分割精度。16 张缺陷图旧规则共标 956 个正 patch，新规则共标 542 个；逐图差异见 `data/black_polygon_supervision_2026-10-25/comparison.json` 的 `label_audit`。

先用旧六折权重重新推理，69 帧逐帧分数与归档结果最大差 **0.0**，确认基线重放。复核旧权重时产生的模型初始化会消耗 PyTorch 随机状态，脚本已在该操作前后保存、恢复状态，使新实验与原 M1 逐折初始化和训练乱序一致。

## 对照结果

| 指标 | 外接矩形监督（旧 M1） | 多边形监督 |
|---|---:|---:|
| 图级 AUROC | 0.9233 | 0.9269 |
| 图级 AP | 0.6607 | 0.6684 |
| 16 张缺陷中的报警 | 13 | 13 |
| 53 张正常中的误报 | 5 | 5 |
| 定位点进入缺陷**外接框** | 7/16 | 7/16 |
| 报警且定位点进入外接框 | 4/16 | 4/16 |
| 定位点进入原始缺陷**多边形** | 6/16 | 6/16 |
| 报警且定位点进入多边形 | 3/16 | 3/16 |

逐帧比较中报警、外接框点命中和多边形点命中均无变化。AUROC/AP 有小幅数值变化，但当前批次没有增加正确报警或精准定位，不构成实用提升；没有独立故障事件，不能据此推断新故障泛化。较严格的多边形命中从 7 降至 6，说明旧外接框定位指标对真实轮廓略宽松。

## 解释范围

这次实验只检验了 **M1 单通道余弦异常图后的小 CNN**，且参考依然是同相机批内留一，可能包含未来帧。它证实旧代码确实丢弃了多边形轮廓，也证实仅把标签改精确，在这一设置和这次故障数据上未提高报警或定位。它不能证明多边形监督对 M2–M6 或新设计的多通道检测头无效；这些模型的输入、训练目标和评分不同。若继续研究，应明确改变的训练信息及验证事件，避免在同一 16 张阳性上反复挑选最好模型。

复现：在有原始 `D:/dataset/black_fabric` 与既有 M1 缓存的环境，执行 `D:/anaconda3/envs/Yolov8/python.exe tools/verify_polygon_supervision.py`。归档中包含六折多边形权重及完整逐帧对照，不依赖重新提取 DINOv2 特征。当前 Yolov8 环境会显示 SciPy/NumPy 兼容警告，本轮训练和指标计算已完成。
