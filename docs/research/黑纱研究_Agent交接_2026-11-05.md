## 4. 当前实现

`src/black_yarn_detector.py::band_feat`：3200×1800 原图，取高度 0.34–0.60 带（468 高）缩放到 448 高，**宽度保持 3200**；588×448 tile，重叠 140。DINOv2 ViT-B/14 最后 8 层拼接，每 patch 6144 维。主干已经重叠切片，不是整图缩到640。

`tools/fewshot_semantic_heads.py`：同机位留一、每位置选最相似参考 R；F、R、原空间 abs(F−R) 各随机投影到64维，再拼余弦异常值，共193通道。缓存 `outputs/black_fewshot_semantic/cache/*.npz`，索引 `outputs/black_fewshot_semantic/index.json`，形状32×228×193。

M4 头：Conv1×1(193→32)→ReLU→Conv3×3(32→16)→ReLU→Conv1×1(16→1)。已是 Transformer 后接 CNN。

`tools/train_black_reviewer_a.py`：从锁定 A 标签重新生成训练目标，校验哈希；六折留测试相机，下一个相机验证，另四机训练；验证正常图 P95 定阈值，验证 loss 选 epoch。两个 uncertain 排除监督，但**仍可能在旧参考缓存里**。

`tools/eval_black_rank_candidate_fc.py`：DINO top10 峰值、2 patch NMS，可加 YOLO top1；候选中心193维＋5×5均值193维＋rank分数和坐标，389维（来源版391维）；训练内 StandardScaler＋L2 LogisticRegression(C=.1)。中心入 A 框标正，框外一patch边缘忽略，其余标负。

YOLO 归档权重来自**较旧16阳性标签**，不是 A 标签重训；六折候选缓存 `outputs/black_yarn_candidate_audit/yolo_fold_top1.json`。归档候选首阶段有相机留出，但不可当公平的 A 版完整 YOLO 基线。

## 6. 最新审计：已验证事实与待验证假设

审计脚本 `tools/audit_black_research_protocol.py`，已完整执行六折402个“折×帧”实例，无训练；结果 `data/black_research_protocol_audit_2026-11-05.json`。包含输入哈希、分组统计、几何、结果重算。402不是独立图片数。

**已确认，修正尚未执行：**

1. 参考仅排除当前图，允许未来/阳性/待定；每patch还可选不同参考帧。缓存未保存reference ID，无法仅靠NPZ统计实际污染率。属于非因果/部署不一致，不能笼统说测试标签直接参与梯度。
2. 各折验证正常仅9、9、3、7、11、9张；Cam3测试折用Cam4的3张估P95，且跨相机搬阈值。
3. 复判训练候选由见过该训练图的首阶段模型产生，可能过于容易。需外层训练内部交叉生成；不能直接用全局六折OOF，它可能见过当前外层测试相机。
4. YOLO与DINO落同patch时去重，但YOLO支持/分数丢失。训练14次、验证1次、测试3次；训练含跨折重复。两张失败Cam4所在测试折没有此问题，不能归因为全部瓶颈。
5. `eval_black_candidate_pairwise.py::ranking_loss` 无正候选时对所有scores求max，忽略候选也被纳入。训练未触发阳性无候选；Cam2折的Cam3验证图触发，含1个ignore。未证明该候选每epoch都是最大值。
6. 最后一片起点2612，mod14=8，却按x//14拼到规则格；候选坐标又按3200/228伸展，需统一padding与映射。未证明造成当前中部Cam4错例。

**待受控消融，不能当已证实原因：**

- 6144→64固定投影可能丢判别信息；维数减少96倍不等于损失96倍信息。
- RGB实验用192裁剪→224、WideResNet最终全局池化2048维→训练内PCA32，未保留密集细节、未专门微调。训练2572个负中心候选中65个裁剪与GT框相交（不等于必有缺陷）；“中心是否缺陷”与“裁剪是否含缺陷”监督可能不匹配。
- 粗框/MIL可学到共现背景；同一事件相关帧和多次使用测试结果限制泛化结论。
