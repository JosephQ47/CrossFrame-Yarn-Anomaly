## 3. 实验臂与运行顺序

M0：已有无监督基线，仅引用冻结结果。

M1：每 patch 的现有余弦异常图 → 3×3 小 CNN → patch 缺陷概率。输入只有 1 通道，可检验规则后处理的局限。要求独立训练标签，不能在锁定评测集热图上拟合。

M2：当前特征 F 与同位置选中参考 R 的差异 `|F−R|` → 1×1 降维/线性分类 → patch 缺陷概率。选参考必须仅依赖当前帧之前的允许正常帧，不能读取未来帧或测试标签。

M3：与 M2 相同的差异输入与降维维数 → 3×3 小 CNN → patch 概率。M2/M3 的差异尽量限于邻域建模。

M4：`[F, R, |F−R|, 1−cos(F,R)]` 分别压缩后融合 → 小 CNN。比较“只看差异”与“保留变化前后状态”。

M5：多层独立处理和细节解码器；M6：多尺度适配与 YOLO 风格目标框头。先等 M1–M4 显示真实收益、训练样本与框标注足够，再纳入第二阶段。并行变动太多组件会降低结论可解释性。

## 4. 数据协议

1. 新建可训练清单，逐条记录原图绝对路径、相机、采集时间、事件 ID、运行状态、正常/缺陷、框或掩膜、标签来源及文件哈希。清单脚本遇到锁定目录立即拒绝进入训练/验证清单。
2. 去重后按**缺陷事件**划分训练/验证/测试，同一事件相邻帧只属于一组；正常帧按相机和运行状态分组。不可随机按帧切分。若样本极少，报告独立事件数及单事件影响，不能把同事件大量帧当独立重复。
3. 参考池只含该机位、同运行状态、时间早于当前帧的已确认正常帧。训练、验证、测试之间不共享用于学习或选择的异常帧。参考池生成规则在看测试结果前冻结。
4. 目前只有矩形框 GT：以框与 patch 的几何重叠生成弱监督目标，并标记边界不确定的 patch；不可把整框当成精确像素掩膜声称像素级精度。若新增精确轮廓标注，再做分割指标。
5. 黑纱缺陷训练样本不足时，可以在正常可用帧上做管线验证、无标签特征缓存和形状检查；不能把随机合成异常的分数当真实黑纱缺陷效果。既往合成暗色/手工缺陷方案在当前课题已显示迁移不足。

## 5. 一致性与评价

- 所有新臂固定同一 DINOv2 权重、图像带范围 0.34–0.60、tile 448×588、patch 网格、参考选择协议和训练/验证/测试划分。记录 Python、Torch、timm、GPU、随机种子、训练步数、模型参数和实际运行时间。
- 训练集只用于参数学习，验证集用于阈值与停止轮次；测试集最后一次性评价。优先报告每事件和每相机明细。
- 主指标：**固定正常误报率 5% 时的缺陷事件召回**、独立测试集图级 AP/AUROC、定位点命中及框 IoU≥0.3 召回；记录误报/相机/小时与端到端时延。小样本下每个缺陷对应 6.25 个百分点，不宜仅凭单一百分比宣称稳健提升。
- 若分割标签确实存在，再加 Dice/IoU；框近似像素 AUROC/PRO 必须标注“框掩膜近似”。只在同测试集、同参考协议、同阈值选择规则下计算 M0 与新臂的差值。
- 记录失败图、标签、当前/参考原图、热图、预测框及运行状态。若 M3 提升但时延不符合产线要求，单独报告精度与代价。

## 6. 今晚可执行的最小检查

**现在可以做：**

1. 对可训练候选目录做只读清单和哈希去重；核对锁定目录没有进入训练清单。当前 `factory_fabric_2` 的 2025 图片仅适于白纱正常技术烟测，2026 图片按 F2 测试集锁定。
2. 核对本机 PyTorch、timm、CUDA 与 DINOv2 权重。用一对**明确可用且同机位同状态**的正常帧跑现有特征提取；核对 tile 输出 `(1,1344,6144)`，拼接后带级网格 `32×(W//14)×6144`，数值有限且近似单位长度。
3. 构造同位置余弦图和差异特征，使用 M2/M3 未训练预测头只做前向、反向及保存/加载烟测，输出张量形状、显存峰值和耗时。不报告“识别准确率”。

**开始真实监督训练的门槛：** 有独立于三个锁定测试集的真实黑纱缺陷训练标注，有明确正常参考及采集事件清单，且完成事件级训练/验证划分。达到门槛后优先跑 M1→M2→M3→M4；只改预测头，冻结 DINOv2，缓存特征以节约时间。

如果今晚只有白纱框标注，可以单独做“白纱预训练可运行性”实验，但它不回答黑纱精度是否提高；报告中必须显式标成迁移预实验。

### 已完成的技术烟测（2026-10-23）

脚本：`CrossFrame-Yarn-Anomaly/tools/smoke_supervised_head.py`。使用 `factory_fabric_2` 中 2025-12-19 同机位、相近时刻的两张**白纱正常帧**，不读取冻结黑纱、F2 六月批或现场样本；仅检查单 tile 的 DINOv2 与预测头计算图，未训练或保存模型。运行环境为 `D:/anaconda3/envs/Yolov8/python.exe`、Torch 2.6.0+cu124、timm 1.0.27、CUDA 可用。结果：DINOv2 `(1,1344,6144)`，差异图 `(1,6144,32,42)`，余弦图 `(1,1,32,42)`，小 CNN 输出 `(1,1,32,42)`，梯度均为有限值，脚本返回 `smoke_pass`。该结果只说明管线能运行，不能说明任何黑纱缺陷识别效果。默认 Anaconda Python 导入 torch 时发生 `c10.dll` 初始化失败，运行需选用上述 Yolov8 环境。
