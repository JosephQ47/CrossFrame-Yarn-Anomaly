# 黑纱检测：文献深查与下一版架构设计

日期：2026-10-31。对象是本项目在固定机位浆纱图像中识别黑纱/异色纱缺陷；这里的“黑纱”不是黑色布料分类。检索覆盖直接的纱线/织物缺陷、工业异常检测、冻结 DINOv2 后接可训练头、弱标注、生产线时序和高分辨率。公开文献使用的“black yarn”“foreign yarn”“dark defect”“fabric defect”定义并不统一；以下是与本任务最相关的可核实原始论文和数据源，不宣称收录了所有数据库中的每一篇论文。

检索于 2026-10-31 进行，使用 `黑纱/异色纱 缺陷检测`、`black yarn/dark yarn/foreign yarn fabric defect detection`、`DINOv2 frozen features trainable segmentation head`、`few-shot industrial anomaly detection`、`fabric production video anomaly`、`high-resolution tiled defect detection` 等中英文组合；优先论文官方页面、会议论文、期刊原文和原始数据集页面，剔除只讲普通黑色布分类、没有定位任务或无法核对出处的营销材料。文献与本项目的匹配按“直接同对象”“相邻织物任务”“可迁移架构”区分，表中每篇都写出适用边界。

## 一、先回答核心判断

**方向可行，而且已有明确先例；我们本地 M4 事实上已经是 DINOv2 特征后接小 CNN。** DINOv2 原论文在冻结 patch 特征上训练线性分割头，也展示冻结骨干加适配器/Mask2Former；SimpleNet 使用预训练特征、浅适配器和异常判别网络；SuperSimpleNet 把分割与图像判别分为两个头；Boxes2Pixels 使用冻结 DINOv2 和层级解码器处理只有框的缺陷标注。上述是架构可行性的证据，不是它们在我们的黑纱上必然提升的证据。[DINOv2](https://arxiv.org/abs/2304.07193)、[SimpleNet](https://openaccess.thecvf.com/content/CVPR2023/html/Liu_SimpleNet_A_Simple_Network_for_Image_Anomaly_Detection_and_Localization_CVPR_2023_paper.html)、[SuperSimpleNet](https://link.springer.com/article/10.1007/s10845-025-02680-8)、[Boxes2Pixels](https://openaccess.thecvf.com/content/CVPR2026W/AI4RWC/html/Lendering_Boxes2Pixels_Learning_Defect_Segmentation_from_Noisy_SAM_Masks_CVPRW_2026_paper.html)。

**当前瓶颈不是“有没有接网络”。** 本地 M4 已经把 `F、R、|F−R|、1−cos` 投影为 193 通道并接 `1×1→3×3→1×1` CNN；六折内部为 13/16 检出、7/53 正常误报，报警且定位点命中 12/16。M0 在另一历史协议下表现更好，不能直接作公平增益声明。Cam3 有定位却阈值没过，Cam5 正常大量越线，说明跨相机校准不稳；M0 的前 5 个候选有一张 Cam3 真缺陷完全覆盖不到。简单增加一个全连接层不能同时解决阈值、候选漏覆盖和 patch 分辨率。参见本仓库 `docs/黑纱M1-M6实验总报告_2026-10-25.md`、`docs/黑纱候选融合实验报告_2026-10-25.md`、`docs/黑纱嵌套留相机候选排序复核_2026-10-25.md`。

## 三、建议的新架构：冻结 DINO，学习差异，保留原图细节

### A. 主线：双头时序特征网络，优先级最高

```text
当前原图 I_t ── DINOv2 冻结、最后 8 层 ── F_t (32 × W/14 × 6144)
过去同相机/同状态 8 帧 ── 因果参考选择 ── R_t
                 F_t, R_t, |F_t−R_t|, 1−cos(F_t,R_t)
                         │
       逐层共享可学习 1×1 压缩 + 特征归一化
                         │
        小型方向性 CNN (1×5、5×1、3×3) + 残差
                         ├── patch 缺陷热图／候选中心
                         └── 图像级报警头（top-k 聚合＋局部统计）
```

设计意图：先保留 M0 的异常图作为一条显式输入和安全对照，再让可学习投影代替 M4 的固定随机投影；方向性卷积利用细纱的长条形态；图像级头独立学习正常高分与真正缺陷的区别，避免只用热图最高 1% 均值决定报警。骨干先冻结，训练参数控制在小头量级。这里的“给 DINO 向量标注”是**用原图框/细线/点映射到 patch 位置训练头的输出**，不是手工修改 6144 维向量。框内边缘与未画到的背景设为 `ignore`，正常帧可监督全图负例；至少对疑难帧补少量细线或多边形标注，验证是否能提高定位。DINOv2 原论文和 Boxes2Pixels 支持此设计形式，但本项目最终效果需实验确定。

**可直接编码的第一版规格**：将最后 8 层各 768 通道的 `F_l` 和 `R_l` 经同一个逐层 `768→16` 线性投影，拼成 `F′、R′、|F′−R′|` 各 128 通道，再加连续余弦异常图和 M0 的 P99 候选掩膜，共 386 通道；`1×1:386→64` 后用带残差的 `1×5、5×1、3×3` 轻卷积，输出 patch 热图。图像级头读取热图 top-k、区域面积和 64 通道 pooled 特征，输出独立报警概率。投影权重对当前帧和参考帧共享，参考选择仍在冻结的原始 DINO 空间中执行，避免训练过程中悄悄改变参考协议。这里的通道数是设计值，尚未训练或测时延。

**标注到损失的映射**：正常原图的每个有效 patch 是负例；缺陷框内仅要求至少一个 patch 为阳性（box 内 max/log-sum-exp 多实例损失），框外远离边界的 patch 作负例，框边缘和框内未精标部分暂不赋逐像素真值。对补出的缺陷细线/多边形再加稀疏 patch BCE/Dice；图像级缺陷/正常标签训练独立报警头。先以正常图和公开织物数据训练适配器，再用七月批做开发性微调；缺陷帧按**事件**而非按 patch 数加权，避免同一次故障复制出大量伪独立阳性。损失组合、学习率和停训轮次只能在训练/验证事件上选择，不能用 F2 或未来故障改权重。

### B. 高分辨率局部修正，解决 M0 漏候选

在 A 的热图和 M0 宽松阈值连通域**并集**中取固定上限候选，再从原始筘齿带提取局部裁剪；小型 CNN 在原图局部细节上预测候选真伪、中心或细线/框。两个候选源都不看真值；训练时对“主干漏提但人工框存在”的图保留一个固定网格兜底候选。这样第二阶段有机会看到 Cam3 那张 M0 前五候选漏掉的缺陷，并避免把全图压缩造成的细线丢失。高分辨率与重叠 tile 价值受 [LUSITANOv2](https://www.mdpi.com/2079-9292/15/19/4403) 和 [tiled ensemble](https://openaccess.thecvf.com/content/CVPR2024W/VAND/html/Rolih_Divide_and_Conquer_High-Resolution_Industrial_Anomaly_Detection_via_Memory_Efficient_CVPRW_2024_paper.html) 的结果支持；具体候选规则要在新流盲测前冻结。

### C. YOLO 只作为独立候选分支，不先作为主干

已有完整 YOLOv8s 微调在七月六折为 10/16 检出、8/53 正常误报。很低置信度时虽然有 16/16 候选覆盖，但约 47 框/图，正确 Cam3 候选曾排第 13；内层 OOF 候选排序后仍只有 11/16 检出。因此“YOLO 后再接一个 FC”本地已经试过初版并未解决排序。若采用 C 分支，应在公共织物数据上预训练候选器，训练区域复核头时必须使用**未见图的 OOF YOLO 候选**；比较 B 的增益时计入额外时延、候选数量与误报。冻结 DINO patch 注入检测器 neck/head 的完整端到端方案有 [Frozen-DETR](https://proceedings.neurips.cc/paper_files/paper/2024/file/bf7262e692f3a5c7d676e9e06a1d919a-Paper-Conference.pdf) 先例，但目前数据量不足，排在第三阶段。

### D. 参考池与校准是架构的一部分

三臂共用同一 DINO 特征和**只用过去**的 8 帧参考；相机、状态切换立刻清池，人手和恢复帧不入池。正常校准段单独留出，阈值事前固定；盲测标签不能决定参考是否入池。再单独试验“报警帧不入池/低风险帧入池”的污染控制，但不能把它与 A 的头收益混成一次消融。若位移明显，先做无标签对齐诊断再决定是否加入配准；参考配准方法的邻近先例为 [FabricDefectNet](https://www.jstage.jst.go.jp/article/fiberst/82/7/82_2026-0023/_article/-char/en)。

### E. 无参考单帧支路：解决冷启动和历史缺失

另保留 `I_t→冻结 DINO F_t→轻量检测/分割头` 的单帧方案，只用当前图像，不需要过去 8 帧。它可以借公共织物框数据预训练并用本地黑纱框做开发性适配，专门评估“第一张就能报”的冷启动能力；DINOv2 冻结特征加线性/分割头和公开生产织物数据是技术依据。其缺点是少量本地黑纱与跨相机外观差异可能造成误报，必须单独报告。若 F2 完成**独立盲标并锁定**且存在阳性，单帧方案可以在 F2 上作不依赖故障前参考的图级/框级验证；这个结论不能移植给需历史参考的 A–D 分支，也不能把未知 F2 真值提前用于模型选择。

## 四、从现在起的研究顺序与证据门槛

| 阶段 | 可做工作 | 结果边界／进入下一阶段条件 |
|---|---|
| 0：数据与错误诊断 | 六机位正常/缺陷来源、事件号、相机状态；补 Cam3 模糊标签和 M0 漏候选原图的细线/多边形；统计缺陷在 14 像素网格上的宽度 | 七月 16 张属于**一次故障**，不能当 16 次独立重复；F2 继续盲判，不能边看结果边改模型 |
| 1：正常图预训练 | 用正常连续流训练浅特征适配/判别支路，或在公开 LUSITANOv2 预训练通用缺陷头；单独报告域移，不拿公开集分数证明本地黑纱收益 | 无新黑纱仍能做工程、正常误报和表征学习；合成异常只作辅助，不是黑纱召回证据 |
| 2：A 与 B 消融 | 固定 DINO/参考/数据划分，依次比较 M0、原 M4、A（可学习投影）、A+独立报警头、A+B（高分辨率 ROI）；另列 E 单帧冷启动；每次只增加一个能力；正常阈值按相同前段正常图校准 | 全部逐帧、逐相机、逐事件报告报警且定位正确、正常 FP/小时、拒判、p95 时延与内存；开发批内部结果仅用于筛掉失败方案 |
| 3：独立验证 | 至少一个与七月不同的真实故障事件及前置 8 张同状态参考；正常盲测跨运行状态和日期；与生产 P0 成对比较 | 只有独立故障证据才可谈“提升”；替换产线需更多事件并满足既定漏检、误报和六路资源门槛 |
| 4：可选 YOLO 融合 | 仅当 A+B 仍漏候选且 C 分支候选确实互补，采用 OOF 训练复核头 | 证明净收益和时延后才考虑融合，不从七月一事件调出最优组合 |

**建议先做的最小可审查实现**：保留现役 C# M0 不动；在 Python 影子支路实现 A 的“可学习逐层投影＋双头 CNN”，并保持现有 P0/P1/P2 因果回放接口。先用现有七月数据检查训练可运行、标签映射和六折失败模式；真实准确率结论等待新连续流和独立故障。B 的原图局部网络在确认 A 的漏检来源后再加，避免一次改动过多而无法解释。
