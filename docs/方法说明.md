# 方法说明：DINOv2 多层特征 + 固定机位跨帧同位置参考

## 1. 问题

浆纱机筘齿区在织造深色/黑纱时出现缺陷（形态为**筘齿锯齿被絮状物糊住**，非暗块也非断线），
缺陷区约 110×100 px，占整幅 1920×1080 图的 **0.2%**。

难点不在"小"，而在**没有可用的监督信号**：

- 工厂只积累到 **16 个** 黑纱缺陷实例，且这批数据被锁为测试集禁止训练；
- 有标注的白纱模型迁移到黑纱后 detect 召回 **0**（见 `data/benchmark_scores.csv`）；
- 更根本的是——`scripts/diagnose_signal_exists.py` 的诊断表明，缺陷区与**同一张图内**的
  正常区在低层特征（亮度、对比度、锐度、高频能量、周期强度、Michelson 对比度）上
  **完全不可分**，平均 |z| 全部 < 1.0。

后一条是决定性的：**任何"看单张图找异常"的手工判据在黑纱上注定失败**，因为单图内不存在
可区分的低层信号。要检测，必须引入一个**图外的参考系**。

## 2. 核心思想

工业相机是**固定机位**的。同一台相机在不同时刻拍到的同一像素位置，正常情况下看到的是
同一段筘齿。于是可以把"这里有没有缺陷"改写成一个**无歧义**的问题：

> **这个位置，在该机位的其他时刻，有没有任何一帧长得像现在这样？**

如果没有——那就是异常。这个判据：

- **对颜色天然免疫**：参考帧与当前帧纱色相同，颜色在比对中相互抵消，
  不需要改色增广、不需要域适应；
- **零训练、零缺陷样本、不用任何标签**：骨干网络完全冻结；
- **代价**是要求机位固定、且参考帧以正常为主。

## 3. 流程

```
输入帧
  │
  ├─① 裁筘齿带  y ∈ [0.34, 0.60] × H，缩放到固定带高 448
  │      为什么固定带高：DINOv2 是 patch-14 的，带高决定 patch 网格行数；
  │      带宽放宽会让缺陷在缩放后占的 patch 数变少，与④的面积上限失配
  │
  ├─② 带内切重叠 tile (588×448, overlap 140) → DINOv2 ViT-B/14
  │      取**最后 8 层**的 patch token 拼接（多层是主要增益：L8 > L12 > L4）
  │      重叠区取平均后 L2 归一化 → 带级特征图 (gh, gw, 8×768)
  │
  ├─③ 跨帧同位置比对
  │      参考 = 同相机其他帧在**同一 patch 坐标**的特征
  │      余弦相似度取 **top-1**（最相似的那一帧）
  │      异常度 = 1 − top1_similarity     ← 逐 patch
  │
  └─④ 图级分数与定位
         对 patch 异常图取 P99 阈值二值化 → 连通域
         图级分数 = **面积 ≤ 55 patch 的最大连通域面积**
         定位     = 该连通域的**重心**
```

## 4. 四个关键设计（按增益排序，均为实测）

| # | 设计 | 增益 | 为什么 |
|---|---|---|---|
| 1 | 图级分数用**连通域面积**而非 max | AUROC 81 → 96.4 | 缺陷是**空间聚集**的一片，噪声是孤立单点。用 max 时噪声峰值与缺陷峰值同量级，导致"纯正常样本定阈"不可行（μ+2σ 只有 6% 召回 = 产线根本没法设阈） |
| 2 | 参考取 **top-1** 而非 top-3 | 产线定阈召回 75% → 94% | 判据变成"有没有**任何一帧**像现在这样"。取 top-3 求平均会把污染帧（参考池里混进的缺陷帧）的相似度摊进来 |
| 3 | 面积上限 **cap=55 patch** | AUROC 96.4 → 98.2 | 人手伸入画面会产生大面积异常块（已目视核实一个 area=57 的误报正是人手）。45~56 为等效平台，≤42 断崖式下降（92.8, 误报 98%）。取 55 离断崖最远且仍低于人手块 |
| 4 | 定阈用**中位数 + 3.5×MAD** 而非 P95 | 阈值从虚高的 18~42 修正到 8~15 | 校准帧若混入少数缺陷帧，P95 会直接取到缺陷分数上，把阈值顶到正常分数的 5~10 倍，检测器完全失效。中位数与 MAD 对少数污染鲁棒 |

另外：定位用连通域**重心**优于平滑热图**峰值**（15/16 vs 14/16）；
LOO 自校准让缓冲满 8 帧即可开始判定（原需 16 帧）。

## 5. 已证伪的方案（不要重复）

在同一 16 缺陷基准上，以下方法**全部 0/16**：

| 类别 | 具体方法 |
|---|---|
| 数据增广 / 域适应 | 改色增广（LCh）、FDA 频域适应、深色改色、哑光改色、手搓 CV 合成暗团/断纱 |
| 迁移 | 真实黑纱微调（灾难性遗忘，白纱能力也一起丢） |
| 通用异常检测 | PatchCore、GLASS（AUROC 58） |
| 手工判据 | structure-tensor 方向一致性、周期塌陷法、同相位周期比对 |
| 同图自参考 | DINOv2 **同图** k-NN（参考取自同一张图的其他位置） |

最后一条最能说明问题：**同样的 DINOv2 特征，参考取自同图则 0/16，取自跨帧则 15/16**。
起作用的不是"更强的特征"，而是**参考系的选择**。

超参层面的负结果：提分辨率 th672/896（零增益，th896 白烧 5.5 倍算力）、
逐位置归一化（15/16 → 7/16）、层数 L4/L12（L8 最优）、
带范围放宽到 0.30–0.65（引入背景，AUROC 96.4 → 94.0）、
皮肤色（YCrCb）入侵抑制（71/71 帧全判含皮肤——工厂锈迹与灰尘都落在皮肤色范围内）。

## 6. 方法的适用边界（红纱上的失败）

同一套代码搬到 **F1 真实工厂红纱**（24 帧、单机位 C6、16 缺陷实例 + 9 张确认正常）上
**失败**：定位 3/15、图级 AUROC 67.0、P95 定阈召回 13% / 误报 11%
（复现脚本 `python/f1_crossframe_eval.py`，明细 `data/f1_crossframe_红纱负结果.json`）。

失败原因**不是颜色**，而是这条方法的前提被破坏：

1. **画面里有会动的东西**。叠加图（`assets/fig3_红纱失败.jpg`）显示异常热图几乎全部落在
   **工人的手**和**白纸卡**上——这两样在帧间位置变化，跨帧比对时它们才是"最不像参考"的区域，
   真正的缺陷被淹没。分数最高的两帧红框都套在手上。
2. **参考池重污染**：24 帧里 15 帧含缺陷。黑纱基准是 71 帧里 16 帧含缺陷（正常帧占 78%）。
3. 面积上限 55 是在黑纱人手块（57 patch）上调的，红纱的机位与视场不同，这个先验不迁移。

**结论**：跨帧参考的有效性取决于**采集纪律**，而非纱线颜色。要在红纱上复现黑纱的成绩，
需要重新采一批满足条件的数据：无人手入侵、无临时物件遮挡、同机位连续多帧、正常帧占多数。

## 7. 硬约束（决定下一步）

**只有 16 个缺陷样本。** 1~2 个样本的波动就是 6~12% 的指标变化，继续调参已无法区分
"真改进"与"过拟合到这 16 个样本"。因此价值重心应转向：

1. 用本检测器当**挖矿器**筛工厂录像扩充基准（94% 召回 / 5% 误报已够用）；
2. 争取更多黑纱录像与更干净的红纱采集。
