# DINOv2 后接预测头与少样本缺陷检测：文献复核

检索日期：2026-10-25。用途：回答“别人怎样把通用特征变成精准缺陷定位，以及我们为何加头后没有提升”。本次检索论文原文、CVF 会议页面、期刊官网与作者仓库；这是面向本项目的证据筛选，不是穷尽性系统综述。本轮不启动训练。

## 1. 结论与两点纠正

**用户提出的方向有明确文献依据。** DINOv2 本身就展示了冻结特征接监督分割头；ChangeViT 展示双图特征及其差分接卷积解码器；PRN 在工业异常检测中学习相对正常原型的多尺度残差。架构可行性已经成立，但这些论文没有证明任何一个追加头都能改善我们的黑纱数据。

此前把“缺少 8 张过去正常参考”说成下一轮算法研究的共同障碍，范围过大。8 是本项目当前部署参数；AnomalyDINO 明确研究至少 1 张正常参考的设定。少参考方法可以继续研究，但不能直接把原 M0 的 8 改成 1 后宣称性能保持，更不能把回顾性结果写成严格时序部署结果。[AnomalyDINO，第 3.1 节](https://arxiv.org/html/2405.14529v2)

本项目目标是**筘齿锯齿被絮状物糊住的局部结构异常**，不是一般断纱或细长裂缝。低层结构相似、正常变化丰富、固定机位参考有价值，是迁移论文方法时必须保留的条件。项目依据：根目录 `agent.md`、本仓库 `docs/黑纱M1-M6实验总报告_2026-10-25.md`。

## 2. 最相关论文与实际做法

### A. 直接支持“特征/差分后接可训练头”

**1）DINOv2: Learning Robust Visual Features without Supervision，2023 预印本。** 冻结骨干，对空间 patch token 训练线性分割头；更强配置融合末四层及多尺度推理，另有 ViT-Adapter＋Mask2Former。说明应保留空间网格，不能用整图向量代替定位特征。它是通用分割证据，不是少样本黑纱实验。

来源：[论文](https://arxiv.org/abs/2304.07193)、[原文语义分割部分](https://pierrefdz.github.io/assets/publis/dinov2/paper.pdf)、[官方代码](https://github.com/facebookresearch/dinov2)。

**2）ChangeViT: Unleashing Plain Vision Transformers for Change Detection，2024 预印本，本记录核对 v1。** ViT-S 用 DINOv2 初始化；每层将 `F1、F2、|F1−F2|` 拼接，用卷积提取差异并逐级上采样，BCE＋Dice 监督变化图。同时有细节分支和特征注入，不等于只在冻结 DINOv2 后追加小 CNN。其遥感配对标注与运动中的纱帘也不同。

来源：[原文 III-A、III-C 式 5–8、IV-A](https://arxiv.org/html/2406.12847v1)、[作者代码](https://github.com/zhuduowang/ChangeViT)。

**3）Prototypical Residual Networks for Anomaly Detection and Localization（PRN），CVPR 2023。** 冻结 ResNet-18 部分特征层，从正常训练图构建多尺度原型；输入特征与最近原型求残差，再经多尺度融合、注意力和卷积解码输出异常掩膜。每子数据集使用 10 张真实异常训练图，并增加扩展、模拟异常。不是 DINOv2，也不等于“仅 10 张同一故障的相邻帧即可泛化”。

特别相关的反例：作者在异常图后加分类网络，没有观察到超过 top-K 分数汇总的提升（第 3.5 节）。因此不能把“再接一个全连接”当作必然有效的原因。

来源：[CVPR 正式入口](https://openaccess.thecvf.com/content/CVPR2023/html/Zhang_Prototypical_Residual_Networks_for_Anomaly_Detection_and_Localization_CVPR_2023_paper.html)、[全文第 3、4.1 节](https://arxiv.org/html/2212.02031v2)。

**4）SuperSimpleNet: Unifying Unsupervised and Supervised Learning for Fast and Reliable Surface Defect Detection，ICPR 2024；作者仓库另列 JIMS 2025 扩展。** 本次核对 2024 原文：WideResNet 特征经过线性适配，按空间掩膜注入特征噪声，训练分割头；另用卷积、池化和全连接输出整图分数。可仅用合成异常，也可结合真实异常掩膜。直接启发“定位与报警共同学习”，但替换为 DINOv2 差分输入属于我们的改造，不能算论文原样复现。

来源：[原文第 3.1–3.5 节](https://arxiv.org/html/2408.03143v1)、[官方代码](https://github.com/blaz-r/SuperSimpleNet)。

### B. 缺陷样本不足时，别人怎样训练

**5）AnomalyDINO: Boosting Patch-based Few-shot Anomaly Detection with DINOv2，WACV 2025。** 将一张或少量正常图的 DINOv2 patch 特征存入库，按最近正常 patch 距离生成异常图，不训练缺陷头。这是少正常样本方法，不能与“少量带标注缺陷监督”混称。其跨位置匹配与我们的同位置约束不同；本地任意位置 PatchCore-DINOv2 已有较弱结果，不能因名字不同便完整重跑。

来源：[全文第 3 节及设定分类](https://arxiv.org/html/2405.14529v2)、[WACV 论文](https://openaccess.thecvf.com/content/WACV2025/papers/Damm_AnomalyDINO_Boosting_Patch-Based_Few-Shot_Anomaly_Detection_with_DINOv2_WACV_2025_paper.pdf)、[官方代码](https://github.com/dammsi/AnomalyDINO)。

**6）DeSTSeg: Segmentation Guided Denoising Student-Teacher for Anomaly Detection，CVPR 2023。** 对正常图合成异常，学生从受损图学习恢复正常教师特征，再用合成掩膜监督分割网络融合多层师生信息。它说明差异融合可以学习，且不必完全依赖真实缺陷标签；但差异来自教师/学生，不是两张真实时间帧。

来源：[CVPR 原文摘要与方法](https://openaccess.thecvf.com/content/CVPR2023/papers/Zhang_DeSTSeg_Segmentation_Guided_Denoising_Student-Teacher_for_Anomaly_Detection_CVPR_2023_paper.pdf)。

**7）Dinomaly: The Less Is More Philosophy in Multi-Class Unsupervised Anomaly Detection，CVPR 2025。** 使用 DINOv2 系列特征、带噪瓶颈及 Transformer 解码器学习正常特征重建，以重建差异定位异常。可避免依赖真实缺陷训练，但它主要评估多类别正常训练设定，不能理解为几张正常图必然够用，也不是 CNN/YOLO 头。

来源：[CVPR 正式论文入口](https://openaccess.thecvf.com/content/CVPR2025/html/Guo_Dinomaly_The_Less_Is_More_Philosophy_in_Multi-Class_Unsupervised_Anomaly_CVPR_2025_paper.html)、[预印本方法第 3 节](https://arxiv.org/html/2405.14325v4)。会议指标与早期预印本版本不混用，本记录不排列其分数。

**8）DRÆM — A Discriminatively Trained Reconstruction Embedding for Surface Anomaly Detection，ICCV 2021。** 利用正常图及合成异常，同时学习重建和缺陷分割，说明异常模拟可提供定位监督。我们的手工图像合成此前已有失败记录；论文成功不能证明那些合成逼近了“筘齿被糊住”的真实分布。

来源：[原文](https://arxiv.org/abs/2108.07610)。

### C. Transformer 接目标检测器的直接例子

**9）RF-DETR: Neural Architecture Search for Real-Time Detection Transformers，ICLR 2026；预印本始于 2025。** DINOv2 骨干配空间投影与 DETR 解码器进行检测/分割；包含检测预训练、微调及架构搜索。证明 DINOv2 可以支撑框检测，但它不是“一个全局向量接 YOLO”，也不能把大规模预训练成绩归因于最后一层。

来源：[论文与录用信息](https://arxiv.org/abs/2511.09554)、[全文第 3 节、表 5–6](https://arxiv.org/html/2511.09554v2)。

**10）基于 Swin Transformer 和 YOLOv5 的无纺布瑕疵检测，刘佳玮、曹江涛、姬晓飞，辽宁石油化工大学学报，2024，44(3):80–88。** Swin 分层主干配 YOLOv5，另加 CBAM、增强及 anchor 调整。是纺织场景的直接先例；多因素共同变化，不能把完整方法增益当作“追加一个检测头”的独立贡献。

来源：[期刊官网](https://journal.lnpu.edu.cn/EN/10.12422/j.issn.1672-6952.2024.03.011)，DOI：10.12422/j.issn.1672-6952.2024.03.011。

## 3. 与我们已做实验的差别

| 已做工作/本地事实 | 文献对应与需要澄清的问题 |
|---|---|
| M2–M4 已做差分、线性头和 CNN；M4 保留当前、参考及差分 | 不能再把“加 CNN”当作没试过。ChangeViT/PRN 还包含正常参照构造、多尺度融合、细节及不同训练监督 |
| 6144 维差分先固定随机投影为 64 维 | 投影是否损失关键区别尚未验证；这是待检验假设，不是已查明失败原因。改学习投影也可能因样本少而更过拟合 |
| 16 张阳性来自同次故障，按相机留出 | 缺陷帧数不能等同独立异常形态数量；文献的 10-shot 成功不是当前单事件训练的充分保证 |
| 框映射为 patch 弱标签 | 掩膜监督论文不能直接照搬“框内全是异常”的训练方式。需核查框中正常筘齿造成的标签混杂 |
| M4 已有 15/16 点命中，但只有 13/16 报警；存在跨相机阈值问题 | 定位与报警是两个目标。SuperSimpleNet 给出联合学习的例子，PRN 又说明增加分类器可能无效，必须与现有汇总评分对照 |
| YOLO＋DINO ROI 全连接排序未胜过基线 | 区域平均特征可能弱化局部结构属于推测；不能据此直接认定换成复杂头就能恢复 |

本地证据：`docs/黑纱M1-M6实验总报告_2026-10-25.md`、`docs/黑纱嵌套留相机候选排序复核_2026-10-25.md`。上述文献提供机制与比较条件，**没有替我们诊断出唯一失败原因**。

## 4. 基于文献的优先顺序（研究建议，尚未运行）

1. **先按 PRN 思路细化“正常参照＋残差学习”。** 保留本地已有效的同相机空间约束，检查参考是否正常、差分是否保留有效通道、框弱标签是否污染；不能原样搬用跨位置最近原型。先核验论文复现的训练信号，再设计与 M4 有明确差异的一个改动。
2. **研究 SuperSimpleNet 的特征空间异常生成与联合定位/报警。** 相比已失败的手工图像改色或贴块，改变的是监督信号的产生方式。先在正常开发图上验证模拟异常是否过于容易识别、是否导致正常结构误报；合成测试分数不能当真实缺陷效果。框与像素掩膜的差异需明确处理。
3. **把 AnomalyDINO 作为少参考协议依据，Dinomaly 作为正常特征重建备选。** 不重复已经有结论的无空间约束 PatchCore 路线。少参考实验须另定阈值并记录冷启动漏检，仍不能把未来帧当过去参考。
4. **暂不优先从头训练完整 DINOv2＋YOLO。** RF-DETR/织物 Swin-YOLO 证明结构可行，但所需的空间适配、检测预训练及监督条件超出“接一层”。若日后比较，优先采用已有检测预训练模型，再做独立事件评测。

可研究的结构概念如下；它是借鉴后的项目假设，不是任一论文的原模型，也不是对准确率的承诺：

```text
当前图／允许的正常参考 → 冻结 DINOv2 的空间特征
                         ↓
            正常参照 + 多通道残差 + 当前特征
                         ↓
           轻量适配与空间解码 → 局部异常图
                         ↓
      固定汇总评分 vs 联合报警头（需同协议对照）
```

下一轮的核心问题应是“改变监督信号或正常参照后，能否在同误报预算下提高报警且定位正确的比例”，而非只比较训练损失或最高 AUROC。已有 M0 结果继续复用；新的算法开发不解除 F2 冻结约束，也不把同次故障多帧解释成新事件泛化证据。
