# 七月原图双人盲审

A、B 两人分别双击 `tools/打开黑纱盲审_A.cmd`、`tools/打开黑纱盲审_B.cmd`，在浏览器中逐张看原图、放大、画框、选择类别并保存。页面先将结果写入各自的本地审核日志；审核完点击“下载我的审核 CSV”导出完整结果。原始空白 CSV 即使在 Excel 中打开，也不会妨碍页面保存；不要把它当作实时结果查看。两人不要互相查看判断。服务只监听本机 `127.0.0.1:8765`；页面地址分别是 `http://127.0.0.1:8765/?reviewer=A` 和 `?reviewer=B`。

仅看原图，不看旧 JSON、模型热图、分数或对方表格。`defect_status` 选 `normal/black_yarn/other_defect/uncertain`；无法判断必须写 uncertain。可以先选图级类别再点“下一张”，缺陷框可之后回头补；尚未判断时也可跳到下一张。画框时在图上拖动最小框，并记录运行状态、手/遮挡及事件 ID。完成后导出 CSV，核对 SHA，再由第三人处理分歧。不得用模型输出给争议帧定真值。F2 使用既有独立盲判模板，不混入本批。
