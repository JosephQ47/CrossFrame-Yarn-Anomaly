# 黑纱监督方向续研：是否继续、如何人工标注

日期：2026-10-31。问题是固定机位浆纱黑纱检测，沿用冻结 DINOv2 和历史正常参考。本文核对原始论文与本仓库 G0–G2 结果；文献在其他工业数据上的数字不视为本地效果。

## 结论

**继续做，但先改监督定义与验证数据，不先扩大网络。** DINOv2 冻结特征后接可训练头有明确先例；混合图像级与少量精细定位标注也有工业缺陷先例。当前本地两种新头均未超过 M4 的“报警且定位正确”12/16：共同训练为 10/16、7/53 正常误报；冻结 M4 定位只训图报警为 11/16、4/53 误报。16 张阳性全来自同一故障，不能当 16 个独立故障验证。人工标注是必要的，但应优先核对真值、正常状态与事件，再有选择地补定位；**没有必要给 6144 维 DINO 向量逐维标注，也不需要一开始给所有图画像素掩膜。**

## 证据及适用边界

| 原始研究 | 支持什么 | 对本项目的限制 |
|---|---|---|
| [DINOv2](https://arxiv.org/abs/2304.07193) | 冻结特征可用浅层探针完成图像和密集任务 | 通用语义特征不保证能表示比 patch 更细的黑纱 |
| [AnomalyDINO，WACV 2025](https://openaccess.thecvf.com/content/WACV2025/html/Damm_AnomalyDINO_Boosting_Patch-Based_Few-Shot_Anomaly_Detection_with_DINOv2_WACV_2025_paper.html) | DINOv2 patch 正常参考可免训练做少样本异常图 | 是保留无缺陷监督基线的理由，不证明黑纱专用监督头会提高精度 |
| [Mixed supervision，Computers in Industry 2021](https://www.sciencedirect.com/science/article/pii/S016636152100066X) | 图像级与少数像素级标注可混合训练检测/分割双网；少量精标可改善弱监督 | 论文有多个缺陷实例和较大的工业数据集，不能把“少量”套成我们同一故障的 16 帧 |
| [SegAD，CVPR 2024](https://openaccess.thecvf.com/content/CVPR2024/html/Baitieva_Supervised_Anomaly_Detection_for_Complex_Industrial_Images_CVPR_2024_paper.html) | 异常图、区域统计与图像级监督可构成第二阶段报警器，无需每张图像素标注 | 其训练集有大量真实缺陷；我们要保留 M0/M4 异常分支并控制过拟合 |
| [SuperSimpleNet](https://arxiv.org/abs/2408.03143)、[期刊扩展](https://link.springer.com/article/10.1007/s10845-025-02680-8) | 区分定位头和图报警头，兼容无监督、弱监督和全监督；图分类头的贡献依赖监督设置 | 我们已试的简单双头反而损害定位，不能直接照搬其结构或性能 |
| [Boxes2Pixels，CVPR Workshop 2026](https://openaccess.thecvf.com/content/CVPR2026W/AI4RWC/html/Lendering_Boxes2Pixels_Learning_Defect_Segmentation_from_Noisy_SAM_Masks_CVPRW_2026_paper.html) | 冻结 DINOv2 加层级解码器可利用框，明确把自动伪掩膜当噪声监督 | 对象并非细纱；框内或 SAM 掩膜均不能直接视为黑纱像素真值 |
| [DLSE-Net，Fabric 2021](https://www.sciencedirect.com/science/article/pii/S0141938221000226) | 织物缺陷可用图像标签做弱监督 | 论文指出卷积与池化可能丢失微小缺陷纹理，提醒保留原图局部细节 |
| [Active labeling，ICML 2023](https://proceedings.mlr.press/v202/li23x.html) | 标注预算有限时，选信息量和覆盖范围高的样本比盲目增加重复标签更合理 | 选样由模型辅助可以，但最终盲测真值不能受预测结果影响 |

## 本项目标注现状和需要纠正的点

`tools/fewshot_m1.py::records()` 从 69 张七月原图的 JSON 读取 `detect` 框，16 张有框、53 张无框；`box_grid()` 只要 patch 中心在框内就设为阳性。G1 沿用该 patch BCE。**这是从框生成的训练目标，不是真正的像素真值**：细黑纱框内可能有大量正常纹理，框边界外还可能有缺陷。共同训练后定位点命中由 M4 的 15/16 降到 11/16，不能断言都由标签噪声导致，但值得用更合适的框损失做单变量消融。

另有一张 Cam3 帧在旧 JSON 标正常、原图仍有疑点；它恰是 Cam2 测试折的验证正常最高分。事后将它从正常校准移除，G2 P95 从 0.639 降到 0.337，Cam2 报警从 2/4 到 4/4。此计算仅说明阈值敏感，**不得用来改正式标签或阈值**。各折只有 5–11 张验证正常，P95 由极少数图决定。现有 F2 69 张盲判模板仍空白。

## 最小人工标注包：按优先级进行

1. **真值及状态复核，必须做。** 两名人员独立看原图，不显示模型分数/热图。每帧记 `正常/黑纱/其他异常/无法判断`、相机、采集时间、运行状态、人手/遮挡/反光、事件 ID。先处理 Cam3 待定帧和 F2；分歧进入第三人或保留待定，不能默认为正常。F2 先锁定盲判和文件哈希，再用于评价。
2. **定位标注，针对真实缺陷和疑难负例做。** 已有 16 张缺陷框先核对：框是否包含完整细线、是否混入大量背景、缺陷中心/走向。对每个独立缺陷事件优先画最小矩形框；很细的目标用中心线或两个端点加宽度，少量代表帧再画精细掩膜用于定位评价。正常图只需图级标签，不画满图框。反光、脏污等易误报正常图标为明确的“难负例”。
3. **连续正常数据，必须做。** 每机位每运行状态分别提供预热参考、阈值校准、盲测正常流，保留帧序、时间和总运行时长。`100` 张/段是当前工程起步目标而非统计保证；最终阈值与误报率按实际时长和要求设定。不得从盲测段反选阈值或污染参考池。
4. **新增真实缺陷事件，最终结论必须有。** 短期采不到时可以继续做训练可运行性、误报和冷启动研究，但不能宣称新架构对未见黑纱提高了召回。复制/增强同一次故障不能充作新事件。

标注对象始终是原图和事件；训练时把框、中心线或掩膜坐标映射到 DINO patch 网格。每个 patch 的 6144 个通道由网络学习权重，不由人手逐维赋义。“人工强化学习”若指人反馈纠正误报，在本阶段落实为受控标注、困难样本再训练和独立验证；无需先建立 RL 奖励模型。

## 下一轮实验顺序与判定

1. **标签闸门。** 完成 Cam3 双人盲审、16 张框审计、F2 锁定；输出标注版本、分歧表、哈希。待定帧不得进入“确定正常”的校准集；这条规则在看模型结果前固定。
2. **只改监督，不改骨干。** 固定 M4 缓存、折划分、种子、训练轮数和阈值协议。比较原框 patch BCE、框内多实例学习（框内至少一个高响应，框外远离边界作负例，边缘忽略）、少量中心线/精细掩膜监督。图报警头冻结定位训练与联合训练分开报告。参考框监督的依据是 Boxes2Pixels 和混合监督研究，但具体 MIL/ignore 宽度必须由训练/验证组决定。
3. **只改校准。** 在同一模型输出上比较固定正常分位数、相机/状态分组校准及拒判策略。阈值仅用独立正常校准段选，评估用后续连续盲测段；报告每小时误报、漏报、定位及各组阈值敏感性。
4. **只有前两项仍留下明确的漏定位，才试高分辨率 ROI；只有证实 193 通道固定投影丢失缺陷信息，才试可学习投影。** 不按七月单次故障最优结果挑大型 YOLO。若监督改进仍不稳定，保留正常参考异常分支，转向正常数据建模与单帧冷启动。

**继续/停止规则**：七月内部结果只能筛掉明显失败设计；真正进入产线影子候选须在独立事件、因果参考、独立正常流上，报警且定位正确优于当前方案，且正常误报/小时、拒判和六路时延满足既定门槛。若始终只有一个故障事件，则只能报告方法探索和正常误报，不能得出“识别更准确”的结论。
